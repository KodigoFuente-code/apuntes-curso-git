# Ejemplos de Markdown

## Introducción

Markdown es un lenguaje de marcado ligero que permite crear documentación con un formato sencillo y legible.

---

## 1. Formato de texto

- **Texto en negrita**
- *Texto en cursiva*
- ~~Texto tachado~~

## 5. Bloques de código

Los bloques de código permiten mostrar comandos sin ejecutarlos.

```bash
git status
git add .
git commit -m "Actualiza documentación"
```
